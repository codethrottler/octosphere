# OctoSphere

Enterprise Employee Workplace & Operations Platform — HRMS + Workforce
Management + Task Management + Internal Service Desk + Analytics, under one
shell.

This is an early build: the shell, shared component library, and the
Unified Dashboard (`/dashboard`) exist; every other module is a
placeholder. See `docs/ARCHITECTURE.md`, `docs/CONVENTIONS.md`, and
`docs/MODULE_PLAN.md` before adding to it.

## Getting started

```bash
npm install
npm run dev
```

Other scripts:

```bash
npm run build   # tsc -b && vite build
npm run lint    # oxlint
npm run preview # preview a production build
```
